# DATABASE DESIGN - HỆ THỐNG QUẢN LÝ TRANG THIẾT BỊ

## 1. TỔNG QUAN

### 1.1. Thông tin Database
- **DBMS**: PostgreSQL 14+
- **Architecture**: Microservices - Multiple Schemas, Single Database
- **Character Set**: UTF-8
- **Timezone**: UTC
- **Backup Strategy**: Daily full backup + Continuous WAL archiving

### 1.2. Database Schemas
```
asset_management_db
├── auth_db           # Auth Service
├── asset_db          # Asset Service
├── procurement_db    # Procurement Service
├── maintenance_db    # Maintenance Service
├── report_db         # Report Service
└── notification_db   # Notification Service
```

## 2. AUTH SERVICE SCHEMA (auth_db)

### 2.1. Table: users
Quản lý thông tin người dùng

```sql
CREATE TABLE auth_db.users (
    id SERIAL PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    username VARCHAR(100) UNIQUE NOT NULL,
    password_hash VARCHAR(255),  -- NULL cho AD users
    full_name VARCHAR(255) NOT NULL,
    phone VARCHAR(20),
    avatar_url VARCHAR(500),

    -- Active Directory fields
    is_ad_user BOOLEAN DEFAULT FALSE,
    ad_user_dn VARCHAR(500),  -- Distinguished Name from AD
    ad_last_sync TIMESTAMP,

    -- Account status
    is_active BOOLEAN DEFAULT TRUE,
    is_verified BOOLEAN DEFAULT FALSE,
    email_verified_at TIMESTAMP,

    -- MFA fields
    mfa_enabled BOOLEAN DEFAULT FALSE,
    mfa_secret VARCHAR(32),

    -- Security
    failed_login_attempts INT DEFAULT 0,
    locked_until TIMESTAMP,
    last_login_at TIMESTAMP,
    last_login_ip VARCHAR(45),

    -- Role & Department
    role_id INT NOT NULL,
    department_id INT,

    -- Timestamps
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    deleted_at TIMESTAMP,

    CONSTRAINT fk_users_role FOREIGN KEY (role_id) REFERENCES auth_db.roles(id),
    CONSTRAINT fk_users_department FOREIGN KEY (department_id) REFERENCES auth_db.departments(id)
);

-- Indexes
CREATE INDEX idx_users_email ON auth_db.users(email);
CREATE INDEX idx_users_username ON auth_db.users(username);
CREATE INDEX idx_users_role_id ON auth_db.users(role_id);
CREATE INDEX idx_users_department_id ON auth_db.users(department_id);
CREATE INDEX idx_users_is_active ON auth_db.users(is_active);
CREATE INDEX idx_users_is_ad_user ON auth_db.users(is_ad_user);
```

### 3.2. Table: assets
Tài sản

```sql
CREATE TABLE asset_db.assets (
    id SERIAL PRIMARY KEY,
    asset_code VARCHAR(50) UNIQUE NOT NULL,
    name VARCHAR(255) NOT NULL,
    category_id INT NOT NULL,

    -- Phân loại theo kế toán
    asset_type VARCHAR(20) NOT NULL CHECK (asset_type IN ('FIXED_ASSET', 'TOOL')),

    -- Thông tin cơ bản
    description TEXT,
    manufacturer VARCHAR(255),
    model VARCHAR(255),
    serial_number VARCHAR(255),

    -- Thông tin tài chính
    purchase_price DECIMAL(15, 2) NOT NULL,
    purchase_date DATE NOT NULL,
    purchase_order_id INT,  -- Liên kết với Procurement Service

    -- Khấu hao (cho Tài sản cố định)
    depreciation_rate DECIMAL(5, 2),  -- %/năm
    depreciation_method VARCHAR(50),  -- STRAIGHT_LINE, DECLINING_BALANCE
    useful_life_months INT,
    residual_value DECIMAL(15, 2),

    -- Bảo hành
    warranty_months INT,
    warranty_start_date DATE,
    warranty_end_date DATE,
    warranty_provider VARCHAR(255),

    -- Trạng thái
    status VARCHAR(50) NOT NULL DEFAULT 'NEW' CHECK (status IN ('NEW', 'IN_USE', 'AVAILABLE', 'MAINTENANCE', 'BROKEN', 'DISPOSED')),

    -- Vị trí
    location VARCHAR(255),
    department_id INT,
    current_user_id INT,  -- Người đang sử dụng

    -- QR Code
    qr_code VARCHAR(500),

    -- Timestamps
    created_by INT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    deleted_at TIMESTAMP,

    CONSTRAINT fk_assets_category FOREIGN KEY (category_id) REFERENCES asset_db.asset_categories(id)
);

-- Indexes
CREATE INDEX idx_assets_asset_code ON asset_db.assets(asset_code);
CREATE INDEX idx_assets_category_id ON asset_db.assets(category_id);
CREATE INDEX idx_assets_status ON asset_db.assets(status);
CREATE INDEX idx_assets_asset_type ON asset_db.assets(asset_type);
```

## 4. PROCUREMENT SERVICE SCHEMA (procurement_db)

### 4.1. Table: purchase_requests
Đề xuất mua sắm

```sql
CREATE TABLE procurement_db.purchase_requests (
    id SERIAL PRIMARY KEY,
    request_code VARCHAR(50) UNIQUE NOT NULL,
    title VARCHAR(255) NOT NULL,
    description TEXT,

    -- Thông tin yêu cầu
    requested_by INT NOT NULL,
    department_id INT NOT NULL,
    priority VARCHAR(20) NOT NULL CHECK (priority IN ('LOW', 'MEDIUM', 'HIGH', 'URGENT')),
    request_date DATE NOT NULL,
    expected_delivery_date DATE,

    -- Loại mua sắm
    procurement_type VARCHAR(50) NOT NULL CHECK (procurement_type IN ('FRAMEWORK_CONTRACT', 'ONE_TIME')),
    framework_contract_id INT,  -- NULL nếu ONE_TIME

    -- Tổng giá trị ước tính
    estimated_total DECIMAL(15, 2),

    -- Trạng thái phê duyệt
    approval_status VARCHAR(50) NOT NULL DEFAULT 'PENDING' CHECK (
        approval_status IN ('PENDING', 'LEVEL1_APPROVED', 'LEVEL2_APPROVED', 'APPROVED', 'REJECTED', 'CANCELLED')
    ),

    -- Phê duyệt cấp 1 (Trưởng phòng)
    level1_approved_by INT,
    level1_approved_at TIMESTAMP,
    level1_notes TEXT,

    -- Phê duyệt cấp 2 (Trưởng phòng HCNS)
    level2_approved_by INT,
    level2_approved_at TIMESTAMP,
    level2_notes TEXT,

    -- Phê duyệt cấp 3 (Ban Giám đốc)
    level3_approved_by INT,
    level3_approved_at TIMESTAMP,
    level3_notes TEXT,

    -- Rejection
    rejected_by INT,
    rejected_at TIMESTAMP,
    rejection_reason TEXT,

    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    deleted_at TIMESTAMP,

    CONSTRAINT fk_purchase_requests_framework_contract FOREIGN KEY (framework_contract_id) REFERENCES procurement_db.framework_contracts(id)
);

CREATE INDEX idx_purchase_requests_request_code ON procurement_db.purchase_requests(request_code);
CREATE INDEX idx_purchase_requests_requested_by ON procurement_db.purchase_requests(requested_by);
CREATE INDEX idx_purchase_requests_department_id ON procurement_db.purchase_requests(department_id);
CREATE INDEX idx_purchase_requests_approval_status ON procurement_db.purchase_requests(approval_status);
CREATE INDEX idx_purchase_requests_request_date ON procurement_db.purchase_requests(request_date);
```

## 9. DATABASE MAINTENANCE

### 9.1. Backup Strategy
```bash
# Daily full backup (3:00 AM)
pg_dump -h localhost -U postgres asset_management_db > backup_$(date +%Y%m%d).sql

# Continuous WAL archiving
archive_mode = on
archive_command = 'cp %p /backup/wal/%f'
```

### 9.2. Index Maintenance
```sql
-- Reindex monthly
REINDEX DATABASE asset_management_db;

-- Analyze statistics weekly
VACUUM ANALYZE;
```

### 9.3. Partition Strategy
```sql
-- Partition audit_logs by month (if data grows large)
CREATE TABLE auth_db.audit_logs_2025_01 PARTITION OF auth_db.audit_logs
FOR VALUES FROM ('2025-01-01') TO ('2025-02-01');
```

### 9.4. Data Retention Policy
- **Audit Logs**: Keep 2 years, then archive
- **Notifications**: Keep 6 months, then delete
- **Email Queue**: Keep 3 months (sent emails), delete immediately (failed after 5 retries)
- **Report History**: Keep 1 year, then archive

## 10. SECURITY CONSIDERATIONS

### 10.1. Encryption
- Passwords: Bcrypt hashing (cost factor 12)
- MFA Secrets: AES-256 encryption at rest
- Backup Codes: SHA-256 hashing
- Tokens: JWT with RS256 algorithm

### 10.2. Row-Level Security (RLS)
```sql
-- Enable RLS for sensitive tables
ALTER TABLE auth_db.users ENABLE ROW LEVEL SECURITY;

-- Policy: Users can only view their own data
CREATE POLICY user_self_policy ON auth_db.users
    FOR SELECT
    USING (id = current_setting('app.current_user_id')::INT);
```

### 10.3. Database Roles
```sql
-- Application role (read/write)
CREATE ROLE app_user WITH LOGIN PASSWORD 'secure_password';
GRANT CONNECT ON DATABASE asset_management_db TO app_user;
GRANT USAGE ON SCHEMA auth_db, asset_db, procurement_db TO app_user;
GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA auth_db TO app_user;

-- Read-only role (for reporting)
CREATE ROLE report_user WITH LOGIN PASSWORD 'report_password';
GRANT CONNECT ON DATABASE asset_management_db TO report_user;
GRANT USAGE ON SCHEMA auth_db, asset_db, procurement_db TO report_user;
GRANT SELECT ON ALL TABLES IN SCHEMA auth_db, asset_db, procurement_db TO report_user;
```
